# KineCheck Evidencia Aplicada

Curso clínico interactivo del ecosistema KineCheck orientado al aprendizaje profundo, el razonamiento clínico y la aplicación crítica de evidencia musculoesquelética.

## Enfoque

- 7 módulos.
- 22 experiencias de aprendizaje.
- Laboratorios de razonamiento.
- Casos clínicos abiertos.
- Cuaderno clínico.
- Biblioteca de evidencia organizada por función clínica.
- Sin exámenes obligatorios ni bloqueo por notas.

## Estructura

La aplicación se publica como sitio estático desde la raíz del repositorio y está preparada para integrarse posteriormente con el sistema protegido de acceso de KineCheck Academy.
